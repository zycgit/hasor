# 2. Bean容器

`hasor-core` 是 Hasor 的基础模块，负责应用容器、依赖注入、Bean 管理、作用域、动态代理、生命周期、事件模型和配置加载。

本章节按能力组织：

- 依赖注入：声明对象之间的依赖关系，并由容器负责创建和装配。
- Bean 管理：管理同类型多实例、唯一 ID 和委托创建。
- 作用域：控制 Bean 的创建和复用方式。
- 动态属性：在运行期提供可变配置值。
- 动态代理：为方法调用增加拦截逻辑。
- 生命周期：在容器启动、初始化和关闭阶段执行业务逻辑。
- 事件模型：在模块之间发布和订阅事件。
- 配置文件：读取 XML、YAML、Properties 以及外部环境变量。
