# v3.2.2 (2018-01-02)

## 影响范围

- Core 上下文与事件、Web 路由和验证

## 更新内容

- 新增
  - 增加 `AppContextWarp`，用于包装 AppContext。
  - `@ValidBy` 增加 `inherited` 属性，控制验证注解是否被继承。
  - 增加 `ValidStrategy`，控制是否继续执行后续验证器。
- 优化
  - `HASOR_LOAD_EVENT_POOL` 默认值由 20 调整为 8。
  - `@MappingTo` 支持为同一处理方法配置多个地址。
