# v3.1.2 (2017-02-19)

## 影响范围

- Core 环境变量与 Web 渲染、验证、布局

## 更新内容

- 新增
  - 区分框架环境变量与用户环境变量：框架参数不影响 `env.config` 加载，显式用户参数会停止加载该文件。
- 优化
  - 渲染框架和 RenderApiBinder 整合到 Hasor Web。
  - `ValidErrors` 合并到 `ValidInvoker`。
  - `HASOR_RESTFUL_LAYOUT` 默认值由 true 改为 false，页面布局不再默认启用。

## 升级说明

- 页面布局不再默认启用；依赖布局的应用需显式启用 `HASOR_RESTFUL_LAYOUT`。
- `ValidErrors` 合并至 `ValidInvoker`，自定义验证代码需调整接口引用。
