# v3.0.0 (2017-01-12)

## 影响范围

- Core Binder 扩展与 Web 调用体系

## 更新内容

- 新增
  - 增加 `ApiBinderCreater` 扩展机制，通过 `ApiBinder.tryCast` 获取扩展接口。
  - 增加 ContainerCreater 扩展，`WebApiBinder` 支持设置请求和响应编码。
  - 增加 `@AopIgnore`，可在类或包级别排除动态代理。
  - 增加 Invoker、InvokerFilter、MappingSetup 和 WebPlugin，统一调用上下文、过滤及路由发现扩展。
- 优化
  - Web 通过 ApiBinder 扩展接入 AppContext，不再需要 WebEnvironment、WebAppContext、WebHasor。
  - 融合 Web 与 RESTful 框架。
  - 移除 v2.4.4 引入的 web-fragment 自动配置，避免重复装配。

## 升级说明

- WebEnvironment、WebAppContext、WebHasor 被移除，Web 扩展通过 ApiBinder 接入。
- 不再使用 web-fragment 自动装配，需要检查应用的 Web 初始化配置。
