# v3.2.0 (2017-10-15)

## 影响范围

- Core 事件、AOP 与 Web 渲染

## 更新内容

- 新增
  - 增加内置 FreeMarker 渲染器，使用时需提供 FreeMarker 依赖。
  - 增加 JSON 渲染器，按 Fastjson、Gson 的顺序查找可用实现，也可通过绑定 `JsonRenderEngine` 指定自定义实现。
- 优化
  - `EventContext` 增加 `fireSyncEventWithEspecial`，支持指定同步事件是否由独立线程执行。
- 修复
  - 修复被代理类包含静态代码块或静态方法时生成错误字节码的问题。
  - 修复 `@Produces` 注解处理中的问题。
