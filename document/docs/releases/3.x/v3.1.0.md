# v3.1.0 (2017-02-15)

## 影响范围

- Core AOP、环境配置与工具

## 更新内容

- 优化
  - 依赖注入遇到父子类同名字段冲突时，在异常中输出字段名。
  - 环境变量名不区分大小写，`env.config` 优先从 WORK_HOME 查找，再从 classpath 加载。
  - 精简 org.more 工具并迁入 Core，整合 classcode，移除不常用的 Event 插件。
  - 增加调试模式下的代理字节码输出。
- 修复
  - 修复 Java 8 下 AOP 产生 `VerifyError` 的问题，不再需要 `-noverify` 绕过该错误。
