# v1.0.0 (2015-07-02)

## 影响范围

- Core 对象绑定与 Web MVC、验证

## 更新内容

- 新增
  - 增加 `DateUtils` 和按名称、类型获取 Provider 的方法，开放 AOP 表达式匹配方法。
  - 合并 Hasor MVC 的 controller、result 插件，支持自定义 Action 返回值处理。
  - 增加基于 `Validation` 的验证机制、表单验证器注册及 `ResultProcess` 异常处理。
- 优化
  - 简化容器工厂与资源插件，调整 Web 模块加载及扩展接口。
- 修复
  - 修复 `asEagerSingleton()` 声明单例失效的问题。
