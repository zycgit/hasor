# v1.2.0 (2015-08-20)

## 影响范围

- Core 对象工具与 Web 参数验证

## 更新内容

- 新增
  - 增加 `@IgnoreParam`，用于在表单注入时忽略指定参数。
- 优化
  - Validation 参数改为泛型，补充泛型判断；验证框架从 MVC 中独立。
  - 完善 ResultDO 的消息处理。
- 修复
  - 修复 BeanUtils 无法获取父类字段和方法的问题。

## 累计更新

以下保留原版本标识；同一能力若有后续调整，以本页主版本的更新为准。

### v1.1.0 (2015-07-09)

- 新增
  - 增加请求作用域数据容器 `ContextMap`，可通过控制器或 AppContext 获取。
  - MVC 支持请求文件名后缀匹配，默认包含 `htm`、`html`、`do`。
  - `Hasor` 增加 `autoAware`，控制器增加 `getModelByName`。
- 优化
  - `AppContextAware` 不再需要通过 ApiBinder 显式声明，简化启动与 Provider 构造过程。
  - `ResourceLoader.exist` 不再抛出 IO 异常。
- 修复
  - 修复加载模块时未正确拦截依赖引发的错误。
  - 修复验证消息未初始化及资源加载器插入空值引发的空指针异常。
