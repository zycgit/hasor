# v2.0.0 (2015-11-27)

## 影响范围

- Core 注入、生命周期与 Web 模块边界

## 更新内容

- 新增
  - 增加 `@Inject`、`@Init`，支持注解注入与初始化。
  - 增加 JVM 关闭钩子及 `WebApiBinderWrap`。
  - 引入 JSON 工具，ASM 升级至 5.0，以支持解析 Java 8 类文件。
- 优化
  - `StartModule` 更名为 `LifeModule`，增加 `onStop`；调整 `onStart` 与容器启动事件的调用时机。
  - 环境初始化与构造方法支持传入 Settings。
  - 移除 `ResultModule`，MVC 插件独立，MVC 框架迁出为 haweb。
- 修复
  - 修复字节码对 `long`、`float`、`double` 的处理问题，排除 java、javax 包中的类参与 AOP。

## 升级说明

- `StartModule` 更名为 `LifeModule`，生命周期实现需补充或调整 `onStop`。
