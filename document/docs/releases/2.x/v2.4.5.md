# v2.4.5 (2016-09-28)

## 影响范围

- Core 绑定元数据、配置注入与环境

## 更新内容

- 新增
  - `BindInfo` 增加 `setMetaData`、`removeMetaData`。
  - `@InjectSettings` 支持 `${...}` 环境变量表达式。
- 优化
  - 简化 JSON 日志处理；调整 `AbstractEnvironment` 初始化接口，以参数控制是否加载 `env.config`。
  - `LinkedCaseInsensitiveMap` 提升为公共工具，调整包位置。
- 修复
  - 修复 Settings 增删改操作中的键名大小写处理，以及环境变量默认值未替换的问题。
  - `remoteEnvVar` 更正为 `removeEnvVar`。
