# v2.4.6 (2016-10-07)

## 影响范围

- Core 作用域与 Web 参数、验证、渲染

## 更新内容

- 新增
  - 增加 `ScopeManager`，完善作用域注册。
  - 增加请求前、响应后事件，支持注入 WebEnvironment、WebAppContext；接口类型参数从 AppContext 获取。
  - RESTful 增加 JSON 后缀拦截，调整上传包位置。
- 优化
  - RenderData 与 Request 属性共享数据，`@ValidBy` 支持多个表单验证器。
- 修复
  - 修复 Action 方法无法传入 Response 的问题。
