# v2.5.0 (2016-10-26)

## 影响范围

- Core 绑定查询、Aware 与生命周期

## 更新内容

- 新增
  - 增加 `ClassAwareProvider`、`InfoAwareProvider` 及 `autoAware` 重载。
  - ApiBinder、BeanBuilder 增加 `getBindInfo`、`findBindingRegister`，允许初始化阶段查询其他模块的注册信息。
- 优化
  - 即时检测绑定 ID 冲突，不再等待初始化后期统一检查。
  - 启动、关闭监听接口提升为公开 API，调整模块发现顺序。
  - 移除 `ContextEvent_Initialized`，其阶段对应 Module 的 `loadModule`。
  - SLF4J API 升级至 1.7.21。
