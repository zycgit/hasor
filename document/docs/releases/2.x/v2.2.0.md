# v2.2.0 (2016-02-24)

## 影响范围

- Core 事件与配置、Web 过滤链

## 更新内容

- 新增
  - 增加事件注册插件，`Settings` 增加 `addSetting`、`clearSetting`。
- 优化
  - 资源插件由 Servlet 改为 Filter，未命中资源时继续交给 Servlet 容器。
  - RESTful 插件改用 Filter，可通过 `renderTo` 或 `ContextMap.setViewName` 指定模板。
  - 工作目录的默认来源由 `USER.DIR` 改为 `USER.HOME`。
  - XML 配置冲突时保留多个值；事件参数由 `Object[]` 改为泛型。
