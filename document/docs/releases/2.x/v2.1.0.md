# v2.1.0 (2016-01-18)

## 影响范围

- Core 注入与关闭、Web 插件

## 更新内容

- 新增
  - 增加 RESTful、templates 插件，提供内置 Web 开发及模板渲染。
  - 增加简化模块配置的插件，验证插件支持 `@ValidDefine`。
- 优化
  - ShutdownHook 在启动时注册、关闭时注销；增加 Environment 包装器。
  - `@Inject` 增加 ByID、ByName 注入方式。
  - 模板和资源插件整合 MIME 处理，移除 JSP 自定义函数。
- 修复
  - 修复 `Shutdown in progress`、Web 启动空指针及 `@Inject` 携带 value 时失效的问题。
