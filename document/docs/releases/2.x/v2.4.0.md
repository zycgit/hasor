# v2.4.0 (2016-07-29)

## 影响范围

- Core 配置模板与 Web 渲染

## 更新内容

- 新增
  - 支持配置模板化，通过替换配置值适配日常、预发、线上等环境，无需修改部署包。
  - 增加 `@InjectSettings`；`AbstractSettings.resetValues` 可通过 `UpdateValue` 更新配置数据。
  - 整合 RESTful、Template、MIME 插件，支持多个渲染器及动态选择渲染方式。
  - 支持注入 `WebAppContext`、`WebEnvironment`。
- 优化
  - 增加 UTF-8 属性文件加载，以 `DecSpaceMap` 组织多个配置空间。
  - `findClass` 从 Settings 移至 Environment，移除 `AbstractMergeSettings`。
  - 资源加载下沉至工具包，资源的 Web 部分与编码插件移至示例。
