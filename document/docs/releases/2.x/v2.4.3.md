# v2.4.3 (2016-08-18)

## 影响范围

- Web 控制器、验证与 Core 工具

## 更新内容

- 新增
  - 增加 `StringEscapeUtils`、`EntitiesUtils` 等 HTML 转义工具。
- 优化
  - 改进启动日志；`WebController` 增加 `putData`，用于向模板输出数据。
  - `ValidErrors` 继承 `RenderData`，简化验证参数访问。
  - 整理 WebController 方法，移除重复接口并补充表单验证操作。
