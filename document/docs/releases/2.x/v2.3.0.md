# v2.3.0 (2016-04-07)

## 影响范围

- Core 注解、作用域、初始化与环境配置

## 更新内容

- 新增
  - 支持配置默认单例或原型模式，增加 `asEagerPrototype`、`@Singleton`、`@Prototype`。
  - 带 `@Init` 的单例在容器启动阶段完成初始化。
  - 支持通过 File 指定配置文件。
- 优化
  - 容器绑定 `EventContext`，可通过注入或容器查询获取。
  - 调整事件插件等待 AppContext 注入的方式，优化启动与线程命名。
  - Hasor 定义的同名环境变量优先于系统环境变量。
