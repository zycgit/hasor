# v2.4.4 (2016-09-05)

## 影响范围

- Web Servlet 集成、异步处理与文件上传

## 更新内容

- 新增
  - 支持 Servlet 2.3 至 3.1，增加文件上传。
  - 增加 `@Async`，在 Servlet 3 容器中启用异步请求，并可用于异步文件上传。
  - 通过 web-fragment 简化 Servlet 3 环境的初始化配置。
- 优化
  - 调整 WebController 方法可见性及工具包结构。
