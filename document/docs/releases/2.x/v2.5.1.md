# v2.5.1 (2016-11-08)

## 影响范围

- Core 外部对象注入与 Web 启动

## 更新内容

- 新增
  - `AppContext.justInject` 可对已有对象执行依赖注入。
  - 增加 `WebHasor`，提供 WebAppContext 初始化入口。
- 优化
  - 启动时可通过 Map 传入环境变量，不再只能使用 `env.config`。
- 修复
  - 修复不同 ClassLoader 下关闭容器时可能发生的异常。
