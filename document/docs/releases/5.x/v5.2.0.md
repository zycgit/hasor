# v5.2.0 (2026-09-12)

## 影响范围

- Core、Config、Web、Boot。

## 更新内容

- 新增
  - 新增 `hasor-boot`，统一普通应用与 Web 应用的启动入口。
  - Action 返回值支持自动渲染，适配 Jackson、Gson、Fastjson 和 Fastjson2。
  - 增加 `WebApiBinder.addResource(...)`，支持静态资源注册、欢迎文件和路由回退。
  - Boot Web 增加可配置的 `/health` 健康检查端点。
  - `@RedirectTo` 支持自定义重定向状态码。
- 优化
  - `@Aop` 内置到 Core，配置扫描统一管理并增加路由冲突检查。
  - 渲染整合到请求执行链，静态资源支持 HEAD 和缓存验证。
  - 统一 Tomcat、Jetty、Undertow 的配置及启动、关闭流程。
  - Core 与 Web 统一使用 Cobble 日志接口。
  - 完善中英文文档与历史版本说明。
- 修复
  - 修复手动、异步、已提交及 204、304 响应的重复渲染。
  - 修复可执行包启动早期的日志加载问题。
  - 修复嵌套 JAR 缺少目录条目时的资源 URL 解析。

## 升级说明

- 自动配置入口统一为 `net.hasor.config.ConfigurationModule`，扫描配置改为 `hasor.loadPackages`。
- Action 返回值默认自动渲染；需要手动处理时，将对应默认渲染引擎设为 `none`。
- 资源注册改用 `addResource(...)`；静态资源不再经过 Hasor 业务过滤器，需同步调整访问控制。
- 更新渲染、CORS、AOP 相关类型的包名引用，并移除旧 `RenderWebPlugin` 装配。
- 内嵌服务配置迁至 `hasor.boot.web`，仅保留一个 Web 容器实现，并按需配置健康检查端点。
