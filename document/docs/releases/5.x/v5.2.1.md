# v5.2.1 (2026-09-23)

## 影响范围

- Core、Config 和文档。

## 更新内容

- 新增
  - 增加 `dependsOn(...)` 和 `@DependsOn`，支持声明 Bean 初始化依赖。
  - 增加 `ApiBinder.getProvider(name, type)`，按名称和类型获取 Provider。
  - 文档站增加中英文 `llms.txt`，提供项目介绍与使用指南索引。
- 优化
  - Provider 在容器初始化通知完成后即可使用。
  - 统一中英文文档编号与导航。
