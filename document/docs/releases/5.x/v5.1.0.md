# v5.1.0 (2026-09-08)

## 影响范围

- Core、Web、Boot Web。

## 更新内容

- 新增
  - 增加 `CircularDependencyException`，报告循环依赖链。
  - `ResourceFilter` 支持 URL 前缀和欢迎文件。
  - `RuntimeListener` 支持通过宿主提供的工厂创建 `AppContext`。
- 优化
  - 避免重复创建和绑定已安装模块。
  - 内嵌 HTTP 容器接口移至 Boot Web。
- 修复
  - 修复根路径 `/` 的路由校验。
  - 修复非根 contextPath 下的静态资源路径解析。
  - 修复初始化未完成时销毁 Servlet 上下文的空指针异常。

## 升级说明

- 内嵌容器相关类型迁至 `hasor-boot-web` 的 `net.hasor.boot.web` 包，需调整依赖与引用。
- 原 `StartupModule` 和注解 AOP 扩展不再由 Core 默认装配，需按需调整启动配置与扩展依赖。
