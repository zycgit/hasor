# v5.0.0 (2026-07-14)

## 影响范围

- Java 运行环境、Core、Web。

## 更新内容

- 新增
  - 增加 `Hasor.run(...)` 快速启动入口。
  - `AppContext` 支持通过 Map 按绑定 ID、类型或名称访问 Bean。
  - 增加内嵌 HTTP 容器的创建、配置和 SPI 接口。
- 优化
  - 公共工具、配置、资源加载和动态代理统一使用 Cobble。
  - 对象提供接口改用 Java `Supplier`。
  - 移除 `Environment`，相关能力由 `AppContext` 提供。
- 修复
  - 恢复 `javax.annotation-api` 依赖及生命周期注解支持。

## 升级说明

- 构建与运行至少需要 Java 17，4.x 应用需调整源码并重新编译。
- 自定义扩展需适配 Cobble、`Supplier` 和 `AppContext` 接口。
- `@InjectSettings` 改从 Settings 读取，环境变量需映射为配置键；类扫描需显式指定包范围。
- `JsonRenderEngine` 不再默认启用 `WriteMapNullValue`，需核对 null 字段输出。
