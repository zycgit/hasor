# v5.0.1 (2026-07-14)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>hasor-core</artifactId>
    <version>5.0.1</version>
</dependency>
```

本版本主要调整项目构建与发布流程，Core/Web 的运行逻辑和公开 API 签名保持不变。

## 影响范围

- Core/Web 源码构建与制品发布

## 更新内容

- 优化
  - 增加 Gradle 多模块构建配置，将模块依赖、测试、打包与发布接入 Gradle。
  - 调整版本更新和发布脚本，配合新的构建流程。
  - 修正 `AppContext.findBindingProvider` 的返回值文档，使其与 `Supplier` 签名一致。

## 升级说明

- 从 5.0.0 升级无需因本次构建调整修改业务代码，Java 17 基线保持不变。
- 从源码构建 Hasor 时使用仓库提供的 Gradle Wrapper；使用 Maven 依赖 Hasor 的业务工程不需要因此迁移构建工具。
