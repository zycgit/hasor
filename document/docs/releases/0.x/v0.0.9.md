# v0.0.9 (2014-09-21)

## 影响范围

- Core 依赖注入与上下文

## 更新内容

- 新增
  - 依赖注入使用 `InjectMembers` 接口。
- 优化
  - 简化 AppContext 实现层次和 context 结构，不再依赖 Guice 或 Spring。
  - 模块通过 `start` 传入，不再使用 `addModule`；移除 `getParent`。
