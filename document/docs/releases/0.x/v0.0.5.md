# v0.0.5 (2013-11-25)

## 影响范围

- Core 配置加载、插件与缓存

## 更新内容

- 新增
  - 增加 `DomXmlAccept`，将 XML 转换为 `XmlNode` 树。
- 优化
  - 降低 JAR 中 `static-config.xml` 的合并优先级，使外部文件配置优先。
  - 调整 `AbstractAppContext.createInjector`；Cache 键类型由 `String` 改为 `Serializable`。
- 修复
  - 修复 `DecSequenceMap.removeAllMap` 的并发修改异常。
  - 修复 `ApiBinderModule` 未处理 Binder 参数导致插件加载失败的问题。
