# v0.0.3 (2013-10-08)

## 影响范围

- Core 构建与 API 文档

## 更新内容

- 优化
  - 更新父 POM，支持 GBK 编码环境下生成 JavaDoc。
  - 改进 JavaDoc 文档内容。

## 累计更新

以下保留原版本标识；同一能力若有后续调整，以本页主版本的更新为准。

### Hasor Web v0.0.1

- 新增
  - 支持以 `@WebServlet`、`@WebFilter` 声明 Servlet 和 Filter。
  - 支持 `@Controller` 控制器，以及方法级、类级和全局控制器拦截器；控制器可使用单例或多实例模式。
  - 支持 RESTful 路由及路径、查询、请求头、Cookie 等参数注入。
  - 通过 `@ResultDefine` 扩展返回值处理，内置转发、包含、JSON 和重定向处理。
  - 支持通过 XML 配置从 JAR、ZIP、目录和 classpath 加载 Web 资源。

### Hasor Web v0.0.2

- 新增
  - WebApiBinder 支持指定 Servlet、Filter 的注册顺序。
  - RESTful 服务支持拦截器及 `@Forword`、`@Include`、`@Json`、`@Redirect` 返回值处理。
- 优化
  - 优化异常信息及 JavaDoc 构建，移除原 MIME 相关代码。
- 修复
  - 修复 RESTful 服务无法正常发布的问题。
  - 修复通过 WebApiBinder 注册的 Filter 启动顺序不可控的问题。
