# v0.0.1 (2013-09-15)

## 影响范围

- Core 容器、模块、配置与 Web 模块边界

## 更新内容

- 新增
  - 增加 `@GuiceModule`，用于将 Guice 模块引入 Hasor。
- 优化
  - 重构 Core、AppContext 和 Settings；`InitContext` 功能合并到 `Environment`。
  - `ApiBinder` 增加模块依赖管理。
  - `HasorModule`、`HasorEventListener`、`XmlProperty` 分别更名为 `Module`、`EventListener`、`XmlNode`。
  - XML 配置解析改用 SAX，不再依赖 `ns.prop`，`config-mapping.properties` 不再必须解析。
  - 合并 `onReady` 与 `onInit` 生命周期阶段，删除销毁过程。
  - Web 支持从 Core 移至 Hasor Web；整理 `net.hasor` 包结构、类扫描与集合工具。
  - `@Module` 更名为 `@AnnoModule`。

## 累计更新

以下保留原版本标识；同一能力若有后续调整，以本页主版本的更新为准。

### v0.0.1.20130831-M1 (里程碑)

- 新增
  - 提供模块生命周期调度、依赖循环检查，以及强依赖、弱依赖和依赖反制规则。
  - 支持 JSR-330 依赖注入，通过 `@Bean` 管理对象，可在 Binder 中使用 Guice 接口。
  - 提供 `@Before` 注解式 AOP，以及同步、异步事件 API。
  - 支持自定义 XML 配置解析和配置变更监听。
  - 提供 Servlet、Filter、Session 和 ServletContext 监听器的注解声明。
