# v0.0.12 (2015-05-09)

## 影响范围

- Core 模块组织、事件与 Web 集成

## 更新内容

- 新增
  - 将 Web 与部分 Quick 插件合并到 Core。
  - Web 增加 shutdown 生命周期支持、MIME 类型获取工具及 Servlet 请求、响应、Session、Context 接口绑定。
  - 增加 JSP 标签库和 `@Aop` 注解插件。
  - 请求与响应默认采用 UTF-8 编码，资源插件支持从 classpath、文件路径和 ZIP 中加载资源。
- 优化
  - `StandardEventManager` 改为无锁实现。
  - 移除自有日志封装，改用 SLF4J，处理 JDK 日志的类加载器问题。

## 累计更新

以下保留原版本标识；同一能力若有后续调整，以本页主版本的更新为准。

### v0.0.10 (2015-04-03)

- 新增
  - 增加 shutdown 生命周期阶段及 `StartModule`。
  - 增加 Future 工具包、`ApiBinderWrap`、`SettingsWarp` 和对象字符串构建工具。
- 优化
  - 移除 SLF4J 依赖，使用 JDK 日志并拆分 `org.more.logger` 工具包。
  - 补充无参构造、泛型信息读取及内部 Provider、元数据适配实现。
- 修复
  - 修复特殊 ClassLoader 环境下重复加载类的问题。
  - 修复 `AbstractSettings` 多线程下可能出现的 HashMap 死锁。
  - 修复设置 Java 系统属性后环境变量无法识别，以及扫描不到父类接口实现的问题。

### v0.0.11 (2015-04-24)

- 修复
  - 修复 `LoggerHelper` 多次输出日志时产生堆栈溢出的问题。

### Hasor Web v0.0.8

- 新增
  - 增加 shutdown 生命周期阶段。
  - 增加获取 MIME 类型的工具模块。
- 优化
  - 日志输出切换为 LoggerHelper，环境变量接口适配 Core 的变化。

#### 升级说明

- 删除 `RRUpdate`，Request、Response 不再通过依赖注入方式注入到类中。
