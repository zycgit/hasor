# v0.0.8 (2014-07-26)

## 影响范围

- Core 类型绑定、作用域与模块机制

## 更新内容

- 新增
  - 确立类型绑定与 Bean 机制，支持 Scope、Provider，增加 `EventContext`。
  - 内置 AOP 接口，不再直接依赖 AOP Alliance。
- 优化
  - 简化主要接口，解除对 Guice 的强制依赖。
  - `findBean`、`findProvider` 更名为 `findBindingBean`、`findBindingProvider`。
  - 删除原有 start、stop 生命周期及插件生命周期支持，移除模块代理和启动依赖检查。
  - 插件迁至 Hasor Quick，精简 JSON、OGNL 及其他工具包。

## 累计更新

以下保留原版本标识；同一能力若有后续调整，以本页主版本的更新为准。

### Hasor Web v0.0.6

- 新增
  - WebApiBinder 支持通过 RegisterInfo 绑定。
- 优化
  - 调整主要接口以解除对 Guice 的强制依赖。
  - 插件移至 Hasor Quick，请求与响应编码设置改由插件提供。
- 修复
  - 修复 JSTL 标签 `fireEvent` 无法正常工作的问题。
  - 适配 Core 模块代理类型的变化。

#### 升级说明

- 不再由 Web 直接提供 `requestEncoding`、`responseEncoding` 设置。
