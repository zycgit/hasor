# v0.0.4 (2013-11-11)

## 影响范围

- Core 插件、环境、日志与生命周期

## 更新内容

- 新增
  - `Environment.isDebug` 可判断是否以调试模式启动。
  - 增加日志级别判断及 Trace 日志输出方法，输出前检查对应级别是否启用。
  - 增加 `ServicesRegisterHandler` 服务注册机制及模块启动、停止事件。
  - `ApiBinder`、`AppContext` 补充 BindingType 工具方法。
  - 增加 Cache、Aware 插件，支持向对象注入 `AppContext`，并输出插件加载状态。
- 优化
  - Gift 更名为 Plugin，定位为框架功能插件；移除 `giftSupport` 配置。
  - `ContextEvent_Stop` 更名为 `ContextEvent_Stoped`。

## 累计更新

以下保留原版本标识；同一能力若有后续调整，以本页主版本的更新为准。

### Hasor Web v0.0.3

- 优化
  - ZIP 资源加载器缓存条目名称，减少反复打开压缩包的次数。
- 修复
  - 调整调试模式下 classpath 资源缓存的刷新行为，便于开发调试。
  - 资源不存在时返回 HTTP 404。
