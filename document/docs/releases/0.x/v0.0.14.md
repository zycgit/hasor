# v0.0.14 (2015-06-17)

## 影响范围

- Core 配置与结果消息

## 更新内容

- 新增
  - `Settings` 增加 `merageXmlNode`，用于汇聚 XML 节点。
- 优化
  - Result 增加 Message 消息传递机制。
- 修复
  - 修复日志直接输出格式化占位字符的问题。
  - 修复多配置文件下主配置失效，以及同一模块在多个 `static-config.xml` 中重复加载的问题。
