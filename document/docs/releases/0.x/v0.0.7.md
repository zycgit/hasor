# v0.0.7 (2014-01-17)

## 影响范围

- Core 配置、事件、扫描与插件

## 更新内容

- 新增
  - `Settings` 支持设置配置值，并可通过 `.` 获取根节点；`Environment` 支持设置扫描范围。
  - 增加 `@GlobalAop`、`PluginHelper` 和 `AbstractAppContext.addGuiceModule`。
- 优化
  - 类扫描由 `Class.forName` 改为字节码解析。
  - `getNameSpace` 更名为 `getSetting`，`clean` 更名为 `cleanCache`，`GlobalProperty` 更名为 `FieldProperty`。
- 修复
  - 修复扫描不到 `AppContextAware` 实现时中止启动阶段的问题。
  - 修复通过 Listener 注解注册的初始化、启动事件未被正确调用的问题。
  - 修复配置根节点与子节点同名导致的数据混乱，以及 `FileEnvironment` 重复加载配置的问题。
  - 修复 `AnnoStandardAppContext` 初始化异常。

## 累计更新

以下保留原版本标识；同一能力若有后续调整，以本页主版本的更新为准。

### Hasor Web v0.0.5

- 新增
  - 增加 JSP 标签库。
  - Web 容器绑定 ServletRequest、HttpServletRequest、ServletResponse、HttpServletResponse、HttpSession、ServletContext。
- 修复
  - 修复控制器拦截器调用标记 `@ControllerIgnore` 的方法时发生递归死循环的问题。
