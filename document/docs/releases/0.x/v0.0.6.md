# v0.0.6 (2013-12-21)

## 影响范围

- Core 日志、AOP、对象转换与生命周期

## 更新内容

- 新增
  - `BeanUtils.copyProperty` 支持 POJO 与 Map 之间的属性复制。
- 优化
  - 日志定位调用位置时不再必须创建异常对象。
  - AOP 拦截器缓存从 `HashMap` 改为 `WeakHashMap`。
  - `Hasor` 移至 core 包；`AppContextAware` 由 Core 直接支持，不再通过 Aware 插件处理。
  - 移除 `ServicesRegisterHandler` 服务注册机制。
  - 整理 `AbstractAppContext` 内部流程，通过受保护方法提供扩展；容器事件在对应阶段完成后发出。
- 修复
  - 修复普通 POJO 的 JSON 序列化异常，使用 `JSONPojoConvertor` 处理。
  - 修复空值向日期类型转换时的异常。

## 累计更新

以下保留原版本标识；同一能力若有后续调整，以本页主版本的更新为准。

### Hasor Web v0.0.4

- 优化
  - 适配 Core v0.0.6 的接口变化。
  - `j2ee` 软件包更名为 `servlet3`。
  - `@Json` 输出的数据前后增加圆括号。
- 修复
  - 修复 `@Json` 无法序列化普通 POJO 的问题。

#### 升级说明

- JSON 输出新增圆括号包裹，直接解析响应内容的调用方需注意格式变化。
