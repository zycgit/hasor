# v0.0.2 (2013-09-29)

## 影响范围

- Core 扩展、模块事件与 AOP

## 更新内容

- 新增
  - 增加 Gift 体系，为非模块类工具提供扩展机制。
  - 以模块类名为事件名，在初始化、启动和停止阶段发出对应事件。
- 优化
  - `DefaultXmlProperty` 更名为 `DefaultXmlNode`，扩展 `XmlNode` 常用方法。
  - `AbstractAppContext` 中的事件声明移至 `AppContext` 接口。
  - `@Before` 更名为 `@Aop`；ASM 升级至 4.0，同步调整 ClassCode。
  - 移除 Mapping 部分支持，相关代码改为示例。
- 修复
  - 修复 `StandardAppContext` 调用无参构造方法时的异常。
