# v4.2.4 (2021-03-17)

## 影响范围

- Core 配置加载、命名空间优先级和配置节点转换

## 更新内容

- 新增
  - `TreeNode` 增加 `toMapData()`，将配置树转换为 Map，保留子节点与多值配置。
- 修复
  - 修复配置树将命名空间误作节点名称的问题，使主命名空间的配置优先级正确生效。
- 优化
  - 移除 `ConfigSource` 中未参与配置读取的命名空间字段，简化配置源定义。

## 升级说明

- 直接构造 `ConfigSource` 的扩展需移除构造参数中的命名空间，改用 `ConfigSource(StreamType, URL)` 或 `ConfigSource(StreamType, Reader)`；`getNamespace()` 同步移除。
- 使用多个命名空间覆盖配置时，应核对修复后的最终取值。
