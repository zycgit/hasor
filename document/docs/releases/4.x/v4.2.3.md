# v4.2.3 (2021-02-26)

## 影响范围

- Core 配置模型、SPI、事件与 Web 异步调用

## 更新内容

- 新增
  - 支持 YAML 配置文件。
  - 增加 `SettingsReader` 扩展接口，统一 properties、XML、YAML 的读取机制。
  - `Invoker` 增加 `asyncExecute`，支持继续执行一个或多个异步请求。
  - `EventContext.getExecutor` 可获取内部事件执行器。
  - `HttpParameters` 支持访问 Request 属性和当前 Invoker。
- 优化
  - Settings 底层存储改为 Map/List 数据模型，重构配置访问逻辑。
  - 配置基础实现支持脱离容器独立使用。
- 修复
  - 调整 SPI 接口，修复注册问题。

## 升级说明

- `AbstractSettings` 更名为 `BasicSettings`，自定义配置实现需更新继承关系。
- `XmlNode` 更名为 `SettingNode`，直接操作配置节点的代码需适配新模型。
