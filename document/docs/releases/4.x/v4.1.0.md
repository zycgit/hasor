# v4.1.0 (2020-02-03)

## 影响范围

- Core 注入、配置、SPI 与 Web 调用和渲染

## 更新内容

- 新增
  - Core 完善 JSR-330 支持，`@InjectSettings` 支持指定配置命名空间。
  - 提供新的 SPI 扩展机制，Web 监听过程由 SPI 接替。
  - 增加 `OneConfig`，统一 FilterConfig、ServletConfig 和 InvokerConfig。
- 优化
  - Servlet 转换为 Mapping 调用，Filter 转换为 InvokerFilter，统一请求处理过程。
  - Core、Web 补充单元测试并修复潜在问题。
  - MIME 类型优先从框架配置获取，未找到时再向 ServletContext 查询。

## 升级说明

- 默认配置文件由 `hasor-config.xml` 改为 `hconfig.xml`，不再提供原环境参数属性文件机制，`hasor-env-properties` 失效。
- `@Produces` 只负责响应 Content-Type，不再决定采用哪个渲染器。
- 移除 `ListenerPipeline` 和 `RenderInvoker.lockViewType` 相关方法，自定义扩展需要调整。
- 主配置命名空间由 `http://project.hasor.net/hasor/schema/main` 改为 `http://www.hasor.net/sechma/main`。
