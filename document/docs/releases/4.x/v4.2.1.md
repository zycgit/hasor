# v4.2.1 (2020-10-16)

## 影响范围

- Core 动态属性、配置读取、SPI 与模块生命周期

## 更新内容

- 新增
  - 增加 `PropertyDelegate`，动态扩展 Bean 属性及对应的 getter、setter。
  - `InputStreamSettings` 增加 `addReader`，支持追加配置读取来源。
  - ApiBinder 支持 `toTypeSupplier`。
- 优化
  - 加载 `xxx-hconfig.xml` 时去重。
  - 多个构造方法声明 `@ConstructorBy` 时，优先选择参数数量最少的构造方法。
  - 模块可在 `loadModule` 中抛出 `IgnoreModuleException`，跳过该模块的启动和停止回调。
- 修复
  - 修复 `loadSpiListener` 未按预期注册的问题，使 `@Spi` 注解正确参与注册。
  - 修复未引入 Web 依赖时普通控制台应用启动失败的问题。

## 升级说明

- `@AopIgnore` 更名为 `@IgnoreProxy`，同时控制 AOP 和动态属性代理。
