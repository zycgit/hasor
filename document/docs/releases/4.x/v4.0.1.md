# v4.0.1 (2019-05-12)

## 影响范围

- Bean 注册、渲染器声明和 Web 调用上下文

## 更新内容

- 新增
  - `Invoker` 增加 `ownerMapping` 和 `fillForm`，提供当前路由与表单填充操作。
- 修复
  - Bean 注册失败时回滚本次注册，避免容器保留未完成的绑定。

## 升级说明

- `@Render` 从声明 URL 后缀改为声明渲染器名称及其 MIME 类型，旧渲染配置需要调整。
- 移除 `InMapping`；独立 Boot Maven 插件不再保留，启动能力整合到 Core。
