# v4.1.2 (2020-03-04)

## 影响范围

- Web 响应渲染、转发与 Core 类型创建

## 更新内容

- 新增
  - 增加 `@RenderType`、`@ForwardTo`、`@RedirectTo`，分别声明渲染器、请求转发和重定向。
  - 增加 JSON 渲染实现及资源过滤器。
- 优化
  - `TypeSupplier` 增加类型判断和组合能力。

## 升级说明

- 移除 `RenderEngine.initEngine`，自定义渲染器需要适配接口变化；响应类型可通过 `Invoker.contentType` 设置。
