# v4.1.4 (2020-04-30)

## 影响范围

- Core SPI 仲裁与 Web 执行链

## 更新内容

- 优化
  - SPI 使用 `SpiJudge` 仲裁多个监听器的选择、顺序和返回值。
  - 参数解析扩展整合到 `PreExecuteChainSpi`，精简调用链扩展点。

## 升级说明

- `InvokerCreater`、`CreatorProvisionListener` 等类型名称订正，旧 import 需同步调整。
- `SpiInterceptor` 改为 `SpiJudge`，`CollectScopeListener` 改为 `CollectScopeChainSpi`。
