# v4.2.2 (2021-01-21)

## 影响范围

- Core 生命周期、配置、Provider 与 Web 参数处理

## 更新内容

- 新增
  - `Hasor` 支持单独构建 Environment、Settings。
  - `XmlNode` 增加 `toSettingMap`、`toSettingsMap`，将配置节点转换为 Map。
- 优化
  - `AppContext` 实现 `Closeable`，关闭时调用 `shutdown`。
  - 扩充 `Provider` 接口，Hasor SPI 兼容标准 Java SPI。
  - 优化 BeanContainer 对 final 字段的处理。
- 修复
  - 修复 `setupEnvironment` 的空指针异常。
  - 修复请求参数不是数组时的处理问题，增加类型转换。

## 升级说明

- Servlet 初始化参数 `hasor-hconfig-name`、`hasor-envconfig-name` 分别改为 `hasor-hconfig-file`、`hasor-env-file`。
- Core 的 provider 工具包迁入公共模块，直接引用这些类型时需更新 import。
