# v4.0.5 (2019-05-27)

## 影响范围

- Bean 销毁、应用等待机制和 Web 参数绑定

## 更新内容

- 新增
  - 支持 `@Destroy`、`@PreDestroy` 和代码配置的销毁方法，在容器停止时清理单例 Bean。
  - `AppContext` 增加 `join`、`joinSignal`，`installModule` 支持数组参数。
  - 同一方法可声明多个 HTTP 方法注解，支持向 Web 方法传入 `ServletContext`。

## 升级说明

- `@ParameterForm` 更名为 `@ParameterGroup`，移除 `@IgnoreParam`。
- 部分 `Hasor` 工具方法迁入 `HasorUtils`；销毁回调仅适用于单例 Bean。
