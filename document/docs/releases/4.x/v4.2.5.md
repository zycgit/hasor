# v4.2.5 (2021-03-31)

## 影响范围

- Core 配置解析、Bean 绑定、动态属性与生命周期注解

## 更新内容

- 新增
  - 配置中的环境变量引用支持 `${变量名:默认值}`，变量未设置时使用默认值。
- 优化
  - 配置项查找恢复为大小写敏感，XML、YAML 和 Properties 保留配置键的大小写。
  - `@Singleton`、`@ConstructorBy`、`@Destroy` 不再标记为废弃，继续保留 Hasor 自身的注解支持。
- 修复
  - 修复 `bindType` 为同一类型指定不同 ID 时仍被误判为重复绑定的问题。
  - 修复 YAML 中对象、列表及对象列表的解析和节点组织问题。
  - 改善无包声明类型在委托动态属性场景下的兼容性。

## 升级说明

- 配置文件中的键名与代码中的查询名称必须大小写一致；依赖旧版大小写不敏感查询的配置需要调整。
- 环境变量默认值可直接写在引用表达式中，不必为每个默认值额外声明环境变量配置。
- YAML 的列表内直接嵌套列表仍不支持，不应将本次修复理解为支持任意 YAML 结构。
