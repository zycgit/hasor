# v4.0.0 (2019-05-09)

最低运行环境升级为 Java 8，核心 API 转向 JDK 标准函数式接口，并调整 Web 扩展与配置加载。

## 影响范围

- Java 基线、Core 绑定与 AOP、Web 过滤链

## 更新内容

- 新增
  - `@Aop`、`@MappingTo` 支持重复声明，`InvokerFilter` 与 `InvokerChain` 支持返回值。
  - 增加 Bean 创建监听能力，可在对象创建时执行回调。
  - 支持以 Reader、InputStream 设置主配置，并通过代码追加配置源。
- 优化
  - Provider、Matcher 的使用分别转向 `Supplier`、`Predicate`，ASM 升级至 7.0。
  - 通过 `META-INF/hasor.schemas` 发现框架配置，支持打包时合并配置索引。
- 修复
  - 修复构造方法处理 `double`、`long` 参数，以及空包下 `package-info` 的 AOP 排除配置未加载的问题。

## 升级说明

- 运行与编译环境至少使用 Java 8；自定义绑定和过滤链实现需适配新的接口签名。
- 合并 JAR 时需保留各模块的 `META-INF/hasor.schemas` 内容，不能只保留一个来源。
