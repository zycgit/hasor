## 历史记录说明

- v0.0.1 至 v4.2.3 的主版本日期统一采用 Maven Central 中 `net.hasor:hasor-core` 制品的 UTC 日期；累计更新中的原版本日期保留历史记录。v4.2.4、v4.2.5 及 5.x 正式版日期采用发布标签所指提交的作者日期，不等同于制品上传日期。
- 早期 Core、Web、JDBC 等模块曾分别发布，仓库标签版本不一定等于所有模块的依赖版本，因此不统一套用依赖示例。
- 页面描述的是对应版本的变化，旧接口不代表当前版本仍然保留。跨版本升级时，应结合中间版本的升级说明阅读。
