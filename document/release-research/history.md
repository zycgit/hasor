# Hasor 历史版本资料（待筛选）

此文件用于整理候选资料，不是发布说明，不加入网站导航。暂不删除、合并或发布任何历史版本。

## 收集范围与可信度

- 覆盖仓库全部 72 个发布标签，最早为 0.0.1，最新为 5.1.0；现有 5.2.0 仍属于开发版，不混入正式标签清单。
- 摘要来自相邻标签间的提交记录与源码差异初审，不是所有历史功能的穷尽说明。提交声称测试通过不等于本次复测。
- 日期保留作者日期和提交者日期，不将二者直接写成正式发布日期。大量早期提交者日期为 2025-10-11，早于此日的作者日期更有历史参考价值，但仍需核实。
- 0.x 部分模块独立版本，例如 0.0.3 标签的提交说明涉及 Core 0.0.3 / Web 0.0.2；不能按标签给所有模块生成同版本依赖。
- 未找到的标签不补造，例如 0.0.10、0.0.11、1.1.0。提交中提到某个版本并不等于存在相应发布标签。
- 仅修改 POM、文件清理或文档的版本单独标识，后续可保留短记录或合并。所有版本保留状态均为“待决定”。
- 完整提交 SHA、原始提交标题、文件增删改名和比较范围保存在 [history.json](./history.json)。主源码分类按路径启发式，不代表严格模块边界。
