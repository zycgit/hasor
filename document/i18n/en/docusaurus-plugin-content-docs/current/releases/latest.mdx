## Historical record notes

- Main-version dates from v0.0.1 through v4.2.3 use the UTC dates of `net.hasor:hasor-core` artifacts on Maven Central; original dates in cumulative changes are retained. Dates for v4.2.4, v4.2.5, and official 5.x releases use the author date of the commit referenced by the release tag, not the artifact upload date.
- Early Core, Web, JDBC, and other modules were released separately. Repository tag versions do not necessarily match every module dependency version, so a uniform dependency example is not applied to all releases.
- Each page describes changes in that version; historical APIs may no longer exist. When upgrading across versions, also read the upgrade notes for intermediate releases.
