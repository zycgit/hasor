# v5.0.0 (2026-07-14)

## Scope

- Java runtime, Core, and Web.

## Changes

- Added
  - Adds `Hasor.run(...)` for quick startup.
  - Adds Map access to beans by binding ID, type, or name through `AppContext`.
  - Adds creation, configuration, and SPI APIs for embedded HTTP containers.
- Improved
  - Standardizes shared utilities, configuration, resource loading, and dynamic proxies on Cobble.
  - Switches object provider APIs to Java `Supplier`.
  - Removes `Environment` and exposes its capabilities through `AppContext`.
- Fixed
  - Restores `javax.annotation-api` and lifecycle annotation support.

## Upgrade notes

- Java 17 or later is required for building and running; adapt and recompile 4.x applications.
- Update custom extensions for Cobble, `Supplier`, and `AppContext` APIs.
- `@InjectSettings` reads from Settings; map environment variables to configuration keys and explicitly specify packages for class scanning.
- `JsonRenderEngine` no longer enables `WriteMapNullValue` by default; check null-field output.
