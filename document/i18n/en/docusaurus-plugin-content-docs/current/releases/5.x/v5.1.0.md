# v5.1.0 (2026-09-08)

## Scope

- Core, Web, and Boot Web.

## Changes

- Added
  - Adds `CircularDependencyException` to report circular dependency chains.
  - Adds URL prefix and welcome file support to `ResourceFilter`.
  - Allows `RuntimeListener` to create `AppContext` through a host-supplied factory.
- Improved
  - Avoids duplicate creation and binding of installed modules.
  - Moves embedded HTTP container APIs to Boot Web.
- Fixed
  - Fixes route validation for the root path `/`.
  - Fixes static resource path resolution under a non-root contextPath.
  - Fixes null-pointer errors during Servlet context destruction after incomplete initialization.

## Upgrade notes

- Embedded container types move to `net.hasor.boot.web` in `hasor-boot-web`; update dependencies and imports.
- Core no longer installs the original `StartupModule` or annotation AOP extension by default; adjust startup configuration and extension dependencies as needed.
