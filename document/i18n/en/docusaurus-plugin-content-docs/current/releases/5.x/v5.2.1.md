# v5.2.1 (2026-09-23)

## Impact

- Core, Config, and documentation.

## Changes

- New Features
  - Adds `dependsOn(...)` and `@DependsOn` for bean initialization dependencies.
  - Adds `ApiBinder.getProvider(name, type)` for Provider lookup by name and type.
  - Adds Chinese and English `llms.txt` files with a project overview and an index of usage guides.
- Improvements
  - Providers become usable after container initialization notifications complete.
  - Aligns Chinese and English documentation numbering and navigation.
