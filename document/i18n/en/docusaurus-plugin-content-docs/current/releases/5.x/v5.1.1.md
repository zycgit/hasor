# v5.1.1-SNAPSHOT (In development)

In development; not yet officially released. This page records changes after v5.1.0.

## Scope

- Boot startup, annotation scanning, Web rendering, static resources, and health checks

## Changes

- Added
  - Unify the Boot entry point for ordinary and Web applications; extend the runtime through the `BootExtension` SPI.
  - Build `@Aop` processing into Core; use `ConfigurationModule` to coordinate scanning of configuration classes, Beans, and Web mappings.
  - Build return-value rendering into Web, with JSON, text, and none modes; select a JSON library automatically or accept a custom serializer instance.
  - Add `ResourceBinder` with multiple resource sources, cache validation, welcome pages, and frontend route fallbacks.
  - Provide a health endpoint in Boot Web that can be disabled, relocated, or extended with Beans; aggregate to DOWN if any check fails.
- Improved
  - Integrate rendering directly into request execution instead of plugin or filter assembly; recognize manual response handling, asynchronous processing, and committed responses to avoid duplicate output.
  - Match Actions before static resources; static resources bypass the Hasor business filter chain.
  - Unify startup-failure cleanup and shutdown lifecycle handling, and extend redirect status code support.

## Upgrade notes

- Use `hasor-boot` as the unified startup module name; the development names `hasor-boot-runtime` and `hasor-boot-core` are no longer used.
- Use `hasor.loadPackages` as the single scan scope; remove separate Config/Web `autoScan` and `scanPackages` settings.
- Move Web container settings to `hasor.boot.web.server` and `connectors.http`. Only one `WebServerProvider` implementation is allowed; providers are no longer selected through configuration.
- Configure default rendering through `hasor.render.defaults.objectEngine/stringEngine`; register resources through `addResource`.
- `HealthCheck` now only declares `check()`. Check names come from container binding information; do not implement `name()`.
