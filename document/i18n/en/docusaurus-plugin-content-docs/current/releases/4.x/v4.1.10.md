# v4.1.10 (2020-07-06)

## Scope

- HTTP headers, SPI arbitration, and application waiting

## Changes

- Added
  - Add `waitSignal` to wait for a signal using an object monitor.
- Fixed
  - Fix Header parameter retrieval errors introduced in v4.1.9.

## Upgrade notes

- Deprecate `joinSignal`; configure an arbitrator when using multiple Notify SPI listeners.
