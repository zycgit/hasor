# v2.4.3 (2016-08-18)

## Scope

- Web controllers, validation, and Core utilities

## Changes

- Added
  - Add HTML escaping utilities including `StringEscapeUtils` and `EntitiesUtils`.
- Improved
  - Improve startup logging; add `WebController.putData` to pass data to templates.
  - Make `ValidErrors` extend `RenderData` to simplify access to validation parameters.
  - Reorganize WebController methods, remove duplicate interfaces, and add form validation operations.
