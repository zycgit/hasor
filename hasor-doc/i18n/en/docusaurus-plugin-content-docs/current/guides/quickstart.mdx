After adding the dependency, you can create Hasor with one line of code.

```java
AppContext appContext = Hasor.create().build();
```

:::tip
An application can contain multiple Hasor environments. Calling the code above multiple times in the same application creates multiple independent `AppContext` instances, and those instances have no relationship with each other.
:::

## Startup Configuration

By default, Hasor loads `hconfig.xml` from the classpath. If the configuration file uses another name, specify it during startup.

```java
Hasor.create().mainSettingWith("my-hconfig.xml").build();
```

You can also write configuration items directly during startup:

```java
AppContext appContext = Hasor.create()
        .addSettings(Settings.DefaultNameSpace, "app.name", "demo")
        .build();
```

## Module

In Hasor, most work starts from the `net.hasor.core.Module` interface. To use a module, write a class that implements this interface. The following code is the first module we implement.

```java
public class FirstModule implements Module {
    public void loadModule(ApiBinder apiBinder) {
        ...
    }
}
```

Then load this module during startup.

```java
Hasor.create().build(new FirstModule());
```

Hasor calls the module method above during startup.


```java title='Loading multiple modules'
Hasor.create().build(new UserModule(), new ClassModule() ...);
```

```java title='A module loading other modules'
public class RootModule implements Module {
    public void loadModule(ApiBinder apiBinder) throws Throwable {
        ...
        apiBinder.installModule(new UserModule());
        apiBinder.installModule(new ClassModule());
        ...
    }
}
```

```xml title='Loading modules from a configuration file'
<?xml version="1.0" encoding="UTF-8"?>
<config xmlns="http://www.hasor.net/sechma/main">
    <!-- Modules loaded by default. -->
    <hasor>
        <modules>
            <module>net.hasor.web.render.RenderWebPlugin</module>
            <module>net.hasor.core.exts.startup.StartupModule</module>
            <module>net.hasor.core.exts.aop.AopModule</module>
        </modules>
    </hasor>
</config>
```
