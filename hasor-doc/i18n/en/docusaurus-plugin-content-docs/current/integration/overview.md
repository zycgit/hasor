# Overview

The current Hasor repository keeps integration support focused on `hasor-boot`:

- **[Hasor Boot Executable Packages](./hasor-boot.md)**: package ordinary Hasor applications as executable Fat Jars.
- **Embedded Web containers**: use `hasor-boot-tomcat`, `hasor-boot-jetty`, or `hasor-boot-undertow` to run `hasor-web` applications directly.

Legacy Spring / Spring Boot integration modules are not present in the current repository, so they are no longer exposed in this documentation.
