# 概要

当前 Hasor 仓库中保留的集成能力主要集中在 `hasor-boot`：

- **[Hasor Boot 可执行包](./hasor-boot.md)**：把普通 Hasor 应用打包成可直接运行的 Fat Jar。
- **内嵌 Web 容器**：通过 `hasor-boot-tomcat`、`hasor-boot-jetty`、`hasor-boot-undertow` 为 `hasor-web` 提供可执行启动方式。

旧版 Spring / Spring Boot 集成模块当前不在代码仓库中，因此文档不再提供对应入口。
